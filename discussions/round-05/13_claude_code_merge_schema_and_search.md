Итого **408 ключей, 57 групп, 53 минус-фразы маршрутизации**.
- **Тексты.** Словацкий с диакритикой. Без «Exkluzívne/Výhradný». Статус указан только там, где он верен: «Oficiálny distribútor» — Meopta, Levenhuk; «Autorizovaný predajca» — Leica. Pulsar и термо в этот пакет не входят (термо на проверке гейта). Нет охотничьих и оружейных слов, нет обещания «skladom» для целого бренда — цена и наличие указываются на странице.
- **Маршрутизация.** Kategórie минусует бренды, «bratislava/predajňa/sonata optics» и ночное видение/термо/дальномеры. Značky a modely минусует магазинные запросы и smart-модели (Stellarscope).
- **Проверки (232/232 PASS):**
  - RSA: 3–15 заголовков ≤ 30 символов, 2–4 описания ≤ 90, без дублей, без запрещённых слов;
  - ни один ключ не стоит в двух группах одной кампании;
  - собственные минусы кампании не блокируют её ключи;
  - **account-level список после diff хода 7 (262 слова) не блокирует ни одного ключа пакета**;
  - **53/53 посадочных: HTTP 200, без редиректа, ≥ 1 товар; карточки — с кнопкой покупки и не «na objednávku».**
- **Находка:** фильтр бренда `?features_hash=509-…` на сайте делает 301 на SEO-подкатегорию (`/teleskopy/teleskopy-celestron/` и т. п.) — в пакете сразу канонические URL ([landing_canonical_urls.json](13_claude_code_attachments/landing_canonical_urls.json)).
- Проверка наличия на карточке — по разметке страницы, это эвристика. Перед включением исполнитель повторяет проверку и ежедневно сверяет наличие героев; карточка без наличия → группа на паузу.
- Бюджет без изменений: 15 + 15 €/день (720 € на окно) — Kategórie и Značky a modely; новые группы Predajňa — внутри её 10 €/день.
