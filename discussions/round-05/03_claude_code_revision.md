- **Источник нарушений политики** — ежедневный `policy_sweep` (cron 03:20): модуль читает статусы всех товаров через Merchant API. - **Свежесть:** реестр действует 30 дней, снимок политики — 3 дня. Битый, неверсионный или из будущего → ничего не допускается. Владелец реестра раз в месяц подтверждает его (новая `generated_at`), иначе новые кампании останутся без товаров — это намеренный безопасный отказ, а сигнал о нём есть в `ads-gate-summary.json`.
- **Реестр v2** ([ads-review.v2.json](03_claude_code_attachments/ads-review.v2.json)): ключ — полная identity `merchant~ONLINE~sk~SK~offer`; у hold и review есть reason, source, date. Список ok пуст; у каждой будущей записи ok обязательны fingerprint, author, reason, evidence, date.
- **Журнал:** после каждого скана `catalog-state/ads-gate-summary.json` — версия правил, evaluated_at, статус и дата реестра и снимка, число hold, счётчики «метка|причина».

  1. У каждой тестовой кампании дата окончания = старт + 27 дней — жёсткая остановка.

- **Измерение (R5-07):**
  - основная покупка — офлайн «Confirmed purchase – CS-Cart SK» (UPLOAD_CLICKS), value = товары с НДС без доставки (подтверждено по коду `func.php` → `gross_revenue`); GA4 Purchase и Order — вторичные, в Conversions не входят;
