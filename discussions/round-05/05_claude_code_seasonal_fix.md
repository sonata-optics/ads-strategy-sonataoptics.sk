## 2. Новая структура SO27 (вместо всего старого)

Полная таблица: [so27_structure.csv](05_claude_code_attachments/so27_structure.csv). Принципы:
- **Standard Shopping, manual CPC** (покупок ~34 за 28 дней на весь аккаунт — мало для tROAS/Max conv value по кампаниям; PMax не возвращаю: Junior-PMax сжёг бюджет без продаж, «удачные» PMax держатся на 1 заказе). Пересмотр стратегии ставок — после 30+ покупок в кампании.
- Фильтр каждой Shopping: **Merchant SK identity ∩ label0 (корень) ∩ label4=ads_ok ∩ цена ≥ 20 €**, всё прочее — excluded. Внутри — «герои» (item_id с подтверждёнными покупками) выше ставкой, непродающие расходники — ниже.
- 6 Shopping: Телескопы · Бинокли+монокуляры+спектив · Микроскопы · Термо (наблюдение) · Аксессуары и остальное (catch-all на 2 982 непокрытых) · Junior (выбор).
- 3 Search: Категории (новая, с вариантами без диакритики — словаки так ищут: dalekohlad 2 800 vs ďalekohľad 750 по MM) · Бренды и модели (пересборка Značky×kategórie) · Predajňa (оставить; **заканчивается 30.11**).
- Минусы: общий список **SO27-shared** (б/у, вакансии, оружейные формулировки, навигация конкурентов EXACT, иностранные языки) + SO27-shop + SO27-search + **SO27-no-hunting только для термо**. Прикрепить ко всем новым **и** к Predajňa; проверка «прикреплено» — отдельный пункт чек-листа запуска (урок §0.1).
- Переход: новые HIGH, старые остаются LOW 72 ч → по факту показов/кликов новых старые 4 Shopping и Značky×kategórie → PAUSED. Удаление не делаем (история, откат = включить старое).

## 4. Бюджет на сезон

**Пиковое окно 27.11–21.12 (25 дней)** — до последних дат доставки к Рождеству; 22.12–31.01 — пониженный темп (таблица, столбец «after»).

Потолок спроса при текущих ставках (оценка cost × (1 − lost_rank) / IS по последним 7 дням): термо ~9×, бинокли ~9×, телескопы ~7,5×, микроскопы ~5×, бренд-Search ~3,7× от текущего расхода. То есть **показы ограничены деньгами, а не ставкой** — но поднимать бюджет до потолка нельзя: доп. показы хуже по качеству, а экономика направлений разная.

| Направление | План €/день (пик) | Логика |
|---|---:|---|
| Телескопы Shopping | 45 | лучший ROAS, 84 % потерь по бюджету → рост ×2,5 |
| Бинокли Shopping | 28 | ROAS ≈ 2, рост ×2, непродающие на 0,20 |
| Микроскопы Shopping | 15 | ROAS ≈ 1, рост ×1,7 только за счёт 50+ € |
| Термо Shopping | 20 | без роста, только ads_ok + ручной ok |
| Аксессуары и остальное | 20 | новое покрытие 2 982 товаров по 0,15–0,35 |
| Junior (выбор) | 6 | вопрос владельцу |
| Search Категории | 15 | новое, сезонный спрос (teleskop 3 100 → ноябрьский пик 5 200 MM) |
| Search Бренды/модели | 15 | 69–85 % потерь по бюджету |
| Predajňa | 5 | как есть, продлить |
| **Итого** | **169 €/день** | ≈ **4 100 € total budgets за 25 дней** (без Predajňa) |

Это ≈ **2,4× текущей базы**; прирост сверх базы ≈ 2 500 € за окно — в пределах среднего варианта ChatGPT (L=2 800). Резерв: не закладывать в кампании 10 %, перераспределять через 7 дней туда, где есть покупки.

**Механика:** каждой SO27 — **campaign total budget** на 27.11–21.12 (жёсткий потолок суммы за период; дневной расход не ограничен, Google может тратить неравномерно). Поле `total_amount_micros` в API этого кабинета существует; путь создания: Google Ads UI/Editor или API (CampaignBudget с периодом на даты кампании). Fallback, если total budget недоступен при создании: average daily budget = значения таблицы, без повышений внутри окна, ежедневный контроль. Total budget при замене кампании не «перезапускать» (сумма израсходованного + остатка ≤ плана).

**Экономический критерий (нужна маржа от владельца):** безубыточный ROAS по нашему value (товары с НДС, без доставки) ≈ 1,23 / m, где m — валовая маржа к цене без НДС. При m = 30 % → ROAS ≈ 4,1; 40 % → 3,1. Правила через 7 дней: ROAS кампании ≥ порога и потери по бюджету > 50 % → +25 % бюджета; ROAS < 50 % порога при ≥ 40 кликах на группу → ставку −30 %; SKU ≥ 25 кликов без покупки → 0,15 или исключить (кроме 200+ €, им 40 кликов).
