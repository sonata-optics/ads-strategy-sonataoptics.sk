## 1. Главная новая находка — R5-CODE-16 (политика GUNS)
Read-only 27.11: два живых объявления **DISAPPROVED, тема PROHIBITED: GUNS** (Словакия):
- **«Predajňa Sonata Optics»** (ad 827728842420, посадочная /kontakt/) — основное объявление по брендовому запросу «sonata optics». Этот запрос дал больше всего кликов в Predajňa и одну покупку; сейчас главное объявление по нему не показывается.
- **«Ďalekohľady | Vortex»** (ad 830169298461).

Остальные объявления с теми же словами меню одобрены. Значит, триггер — не общее меню сайта (в нём есть «Puškohľady» и «Kolimátory» на всех страницах), а содержимое конкретных страниц. На /kontakt/ есть блок отдела **«Poľovnícka optika · termovízie a nočné videnie»**; Vortex у Google ассоциируется с прицелами.
Риск: оружейные темы Google входят в систему предупреждений (strikes). Повторные отклонения по GUNS опасны для всего аккаунта, а не только для одного объявления. Поэтому:
- **Vortex исключён из Search-пакета** (группа бренда и модель Crossfire HD 12×50); товар остаётся только в Shopping, где он продаётся;
- **группы магазина в пакете ведут не на /kontakt/, а на одобренные страницы категорий** (/teleskopy/, /mikroskopy/, /dalekohlady/), как действующие одобренные объявления Predajňa;
- группа «бренд и адрес» остаётся на /kontakt/, но **не включается**, пока владелец не решит, что делать со страницей (например, убрать блок «Poľovnícka optika» или выбрать другую посадочную) — это изменение сайта, решение владельца;
- владельцу стоит проверить в Policy manager, нет ли предупреждения по аккаунту.

## 3. R5-23 — модели, семейства, пересечения
[search_package_v2.py](15_claude_code_attachments/search_package_v2.py) (использует правила и тексты хода 13).
- **Модельные группы** — только полное обозначение (EXACT + PHRASE), плюс минусы конфликтующих вариантов на уровне группы. Пример: AstroMaster 114EQ минусует 114az/az/lt/70/90/130; C8 XLT OTA минусует nexstar/se/cpc/evolution/edgehd/origin…; Karma PLUS минусует pro/ed и другие кратности.
- **Неоднозначные семейства** («celestron c8», «celestron astromaster», «bresser junior teleskop», «levenhuk karma», «sky-watcher explorer», «bresser erudit», «omegon binofield»…) → страница бренда или семейства. Добавлена отдельная группа «Teleskopy | Bresser Junior»; в группе «Bresser» стоит минус «junior».
- **Группы брендов минусуют обозначения моделей** (многословными фразами, например «karma plus», «condor 10x42», «130 eq2»), чтобы полный модельный запрос попадал только в модельную группу.
- «hvezdársky ďalekohľad + бренд» = телескоп: группы «Ďalekohľady | бренд» его минусуют. Детские группы и группы «на звёзды» разведены минусами.
- **Семантический симулятор:** EXACT — весь запрос, PHRASE — непрерывная последовательность слов; минусы account-level (после diff хода 7) + кампании + группы. Требование — **ровно одна** подходящая группа с ожидаемым URL:
  - каждый из 475 ключей приходит только в свою группу;
  - **39 тестовых запросов**: целевой вариант, соседний вариант, неоднозначный запрос, кратности (в том числе 10×56 → без объявления), «туристический 10×42» → страница 10×42, бренд против модели, магазин, очковая оптика → без объявления, ночное видение и smart → без объявления. [Результаты](15_claude_code_attachments/search_semantic_tests.csv).
  - Первый прогон нашёл 25 реальных пересечений (детские и звёздные группы, «hvezdársky ďalekohľad + бренд», обозначения в группах брендов) — все исправлены минусами.
- Итого **475 ключей, 66 групп, 409 минусов; 713/713 проверок, включая 64/64 посадочных** (200, без редиректа, есть товары). [Проверки](15_claude_code_attachments/search_checks.txt) · [посадочные](15_claude_code_attachments/search_landing_check.csv).
- Ограничение: симулятор литеральный и не моделирует близкие варианты Google; после запуска — ежедневный просмотр search terms.
