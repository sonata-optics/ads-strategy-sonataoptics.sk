## 2. Исполнимые деревья (R5-19/20)
[so27_trees.py](09_claude_code_attachments/so27_trees.py) → [so27_trees.json](09_claude_code_attachments/so27_trees.json), [синтетика](09_claude_code_attachments/synthetic_cases_results.csv)
- Форма Google: **не больше одного campaign listing scope** (равенство) на кампанию и **одна группа** с деревом. Бинокли/термо/аксессуары — без scope, `custom_label0` внутри дерева, Others → excluded.
- Порядок на каждом включённом пути: **label4 = ads_ok → [label0 allowlist] → label3 из платных диапазонов → item_id → лист**. Цена проверяется **до** любого выделенного ID: hero/smart/Junior с p_lt20, p_invalid, старым p_0_49 или пустым label3 исключаются.
- Catch-all — явный allowlist из 21 значения label0 (а не «всё прочее»): новая или пустая категория исключена.
- Junior: ID 25828, 64089, 26947, 102391; Others под ценой — excluded.
- Синтетическая матрица: 4 ID × 8 label0 (включая чужой и пустой) × 4 label4 (ok/review/hold/пусто) × 6 label3 (lt20/20_49/50_199/invalid/старый p_0_49/пусто) = **768/768 PASS**, не больше одного маршрута на товар. Проверка структуры: ровно один Others на каждом уровне, без дублей, глубина < 7.
- **Живая проверка (read-only, 7 828 товаров SK Merchant)** — тем же алгоритмом в PaidSync; дерево пересобрано 1:1, **контрольная сумма канонического JSON совпала с Python (61308049)**:

|---|---:|---:|---|
| сейчас (старый p_0_49) | 0 | 0 | Телескопы 595, Бинокли 458, Микроскопы 614, Аксессуары 2 144, Junior 1 |
| после патча label3 | 0 | 0 | Телескопы 601, Бинокли 493, Микроскопы 620, Аксессуары 2 734, Junior 4 |

Термо в обоих случаях 0 — пока нет ручных ok. Junior до патча: только 25828 (остальные трое — p_0_49 → исключены); после патча все четыре.

## 3. Старые маршруты и термо (R5-21)
- **Все 4 старых Shopping, включая термо**, на время параллели получают в listing scope второе измерение `custom_label4 = ads_ok`. Старая термо-кампания тогда показывает только вручную одобренные SKU, иначе ничего. Минус-слова — дополнение, не замена допуска.
- Ценовая защита старых маршрутов: у них нет ценового дерева; сейчас её обеспечивает `google.min_price = 20` (дешевле 20 € в Merchant не отправляется). Это условие внесено в план как стоп-условие: если порог понижают — сначала пауза старых маршрутов.
- **Кандидаты для ручного ok по термо:** [thermal_manual_ok_candidates.csv](09_claude_code_attachments/thermal_manual_ok_candidates.csv) — 174 товара в наличии, ads_review, без ошибок Merchant: 149 наблюдательных устройств по названию и типу (HIKMICRO 29, Pulsar 24, Pixfra 20, Nocpix 16, ATN 14 …), 18 аксессуаров (аккумуляторы, чехлы, держатели — проверить), 7 цифровых приборов ночного видения (CHECK). Для каждого — product_type, main_category/root и **fingerprint v3**; совпадений с оружейной лексикой — 0. Это черновик ролей по названию, **не одобрение**: владелец подтверждает построчно, тогда в реестр пишутся author/reason/evidence/date. Массового ok по бренду нет.
