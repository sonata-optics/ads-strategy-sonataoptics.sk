## ГИПОТЕЗА / вопрос к Code и ChatGPT
Если Sonata в SK будет рекламировать те же смарт-модели (Shopping или поиск), два сайта одного владельца окажутся
в одном аукционе (политика Google Unfair advantage: показ одного объявления на рекламодателя; рост CPC).
Предложение на обсуждение: в ads-gate Sonata для SK держать бренды DWARFLAB / ZWO Seestar / Unistellar / Vaonis /
Celestron Origin вне платной рекламы (free listings можно), а в поиск Sonata добавить минус-слова
seestar, dwarf 3, dwarf mini, dwarflab, unistellar, odyssey, evscope, equinox, vespera, vaonis, celestron origin.
Решение — за владельцем.
