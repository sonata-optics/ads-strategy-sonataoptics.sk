   - Такой спрос закрывается **покрытием Shopping по ID модели**, а не отдельными Search-ключами: у ключей с такой частотой в Google Ads будет статус «мало поисков».

3. **Спрос вне текущих кампаний большой:** meteostanica 3 600 (вместе с группой 5 960), fotopasca 3 500 (8 070), lupa 2 600 (5 380), vlhkomer 1 500, refraktometer 840. Сейчас ничего из этого не рекламируется.

## Ограничения
- Объёмы MM — оценка, а не факт аккаунта. 101 из 187 исходных запросов в MM без данных (0): в основном модели, бренд «sonata optics» и точные кратности. Это «нет данных», а не «нет спроса».
- Хвост по 10/мес (≈4 450 запросов) в CSV не выгружен; он есть в отчёте MM. Для модельной видимости он важнее как подтверждение, чем как список ключей.
- Классификация правилами может ошибаться на отдельных строках. Все решения по минус-словам — предложения.
