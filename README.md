# Мультиагентная рекламная стратегия: Sonata Optics
**Проект:** Sonata Optics (e-commerce оптической техники в Европе)  
**Репозиторий:** `sonata-optics/ads-strategy-sonataoptics.sk`  
**Формат работы:** Multi-Agent Advisory Board (Gemini, ChatGPT, Claude, Grok)

---

## 1. Вводные данные и контекст проекта

### 1.1. Продукт и ассортимент
* **Ниша:** E-commerce оптической и наблюдательной техники.
* **Категории товаров:**
  * Телескопы (астрономия, любительские, полупрофессиональные).
  * Микроскопы (учебные, лабораторные, детские, хобби).
  * Бинокли и зрительные трубы (туризм, орнитология, охота, морские, театр).
  * Тепловизоры, приборы ночного видения и монокуляры (охота, охрана, outdoor).
  * Аксессуары и оптика спецназначения.

### 1.2. География экспансии
1. **Приоритет №1 (Focus Market): Словакия (`.sk`)**
   * Статус: Сайт полностью готов к приёму трафика и продажам.
   * Задача: Немедленный запуск и масштабирование платного трафика (первые продажи, окупаемость, отладка воронки).
2. **Волна №2 (Next Waves):**
   * **Польша (`.pl`)** и **Австрия (`.at`)** — в параллельной подготовке.
   * **Чехия (`.cz`)** — следующий этап запуска.
   * *Требование:* Стратегия для Словакии должна стать модульным шаблоном (framework), адаптируемым под особенности остальных стран CEE/DACH.

## 2. Архитектура мультиагентной работы (AI Multi-Agent System)

GitHub-репозиторий выступает единым источником правды (**Single Source of Truth, SSOT**). Модели не спорят вслепую — каждая итерация фиксируется в версиях файлов Markdown.

### 2.1. Ролевая модель участников
* **Gemini (Архитектура & Анализ Google Ecosystem):**
  * Проектирование структуры данных, Google Shopping / Performance Max, поисковой спрос, SEO/SEM синергия.
* **Claude (Claude Code / Cowork) (Глубокая аналитика & Синтез):**
  * Интеграция с рекламными кабинетами (выгрузка сырых данных, аналитика открутки, расчёт юнит-экономики: CPA, ROAS, AOV, LTV).
  * Анализ смыслов, tone-of-voice, посадочных страниц и CJM (Customer Journey Map).
* **ChatGPT (Стратег, Копирайтинг & Meta Ads):**
  * Разработка гипотез по таргетированной рекламе (Facebook/Instagram Ads, каталоги, dynamic ads).
  * Структура креативов, офферы под боли ЦА, углы подачи (angles).
* **Grok (Контр-экспертиза, Нестандартные гипотезы & Тренды):**
  * Независимый аудит («Red Teaming»), поиск слабых мест и скрытых рисков в предложенных стратегиях.
  * Анализ конкурентной среды, нестандартные каналы (форумы, комьюнити, Twitter/X, инфлюенс-маркетинг охотников/астрономов).

## 3. Регламент итераций (Round-Robin Debate Loop)

Каждое решение проходит обязательный 4-этапный фильтр качества:

```
[1. Proposal (Гипотеза)] 
        ↓
[2. Cross-Review & Red Teaming (Критика и поиск дыр)]
        ↓
[3. Refinement & Consensus (Доработка с учётом критики)]
        ↓
[4. Action Plan / Commit (Финальное решение в репозиторий)]
```

* **Правило запрета формального согласия:** Ни одна модель не имеет права просто сказать «стратегия отличная». Обязательно выявление 2-3 рисков (слив бюджета, несоответствие регуляциям ЕС по тепловизорам, узкая емкость рынка Словакии, проблемы атрибуции).
* **Синхронизация данных:** Данные из рекламных кабинетов (Google Ads, Meta Ads) коммитятся в папку `/data/analytics/` в анонимизированном структурированном виде (JSON/CSV/Markdown), чтобы все агенты читали единую фактуру.

## 5. Первоочередные задачи (Словакия - Фаза 1)

1. **Технический фундамент трекинга:**
   * Проверка Google Tag Manager, GA4 (E-commerce события: `view_item`, `add_to_cart`, `purchase`).
   * Настройка Meta Conversions API (CAPI) с учетом европейского GDPR/Cookie Consent.
2. **Низковисящие фрукты (High Intent Traffic):**
   * Настройка товарного фида Google Merchant Center для Словакии.
   * Подключение локальных словацких прайс-агрегаторов (критично для Словакии: **Heureka.sk**, NajNakup.sk, Pricemania.sk).
3. **Разделение кампаний по юнит-экономике:**
   * Масс-маркет / подарки (детские микроскопы, любительские телескопы до 200€).
   * Высокий чек / B2B / специализированные (тепловизоры, охота, профессиональная оптика 500€ - 3000€+).
