**Максимально полное присутствие Sonata Optics в товарных карточках Google по конкретным моделям; дополнительно — точечные текстовые объявления Search.** Готовим новую структуру по итогам обсуждения. ## 1. Вводные данные и контекст проекта

### 1.1. Продукт и ассортимент
* **Ниша:** E-commerce оптической и наблюдательной техники.
* **Категории товаров:**
  * Телескопы (астрономия, любительские, полупрофессиональные).
  * Микроскопы (учебные, лабораторные, детские, хобби).
  * Бинокли и зрительные трубы (туризм, орнитология, охота, морские, театр).
  * Тепловизоры, приборы ночного видения и монокуляры (охота, охрана, outdoor).
  * Аксессуары и оптика спецназначения.

### 1.2. География экспансии
1. **Приоритет №1 (Focus Market): Словакия (`.sk`)**
   * Статус: Сайт полностью готов к приёму трафика и продажам.
   * Задача: Подготовка запуска и масштабирования после проверки измерения, допуска ассортимента и экономики. Этот документ не разрешает менять живые кампании.
2. **Волна №2 (Next Waves):**
   * **Польша (`.pl`)** и **Австрия (`.at`)** — в параллельной подготовке.
   * **Чехия (`.cz`)** — следующий этап запуска.
   * *Требование:* Стратегия для Словакии должна стать модульным шаблоном (framework), адаптируемым под особенности остальных стран CEE/DACH.

## 5. Первоочередные задачи (Словакия - Фаза 1)

1. **Технический фундамент трекинга:**
   * Проверка Google Tag Manager, GA4 (E-commerce события: `view_item`, `add_to_cart`, `purchase`).
   * Настройка Meta Conversions API (CAPI) с учетом европейского GDPR/Cookie Consent.
2. **Низковисящие фрукты (High Intent Traffic):**
   * Настройка товарного фида Google Merchant Center для Словакии.
   * Подключение локальных словацких прайс-агрегаторов (критично для Словакии: **Heureka.sk**, NajNakup.sk, Pricemania.sk).
3. **Разделение кампаний по юнит-экономике:**
   * Масс-маркет / подарки (детские микроскопы, любительские телескопы до 200€).
   * Высокий чек / B2B / специализированные (тепловизоры, охота, профессиональная оптика 500€ - 3000€+).
