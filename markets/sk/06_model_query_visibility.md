# Приоритет владельца: видимость по конкретной модели
Дата: 15.11.2026. Дополнение владельца после круга 1; обязательно для всех участников круга 2. Предыдущие отзывы сохраняются исторически.

## Цель
Владелец хочет полностью новую рекламную структуру на основании согласованной стратегии, поскольку текущую видимость считает неудовлетворительной.
1. Главный обязательный результат: Sonata Optics представлена товарной карточкой Google по запросу конкретной модели из доступного к продаже и допустимого для Google ассортимента.
2. Второй результат: релевантное текстовое поисковое объявление по той же модели с переходом на её карточку.
Общие показы, трафик по бренду и ROAS не заменяют проверку модельного покрытия. Meta и альтернативные каналы сохраняются в стратегии, но не вытесняют этот приоритет Google.

Стремление владельца к показу по каждому точному запросу — требование максимально полного покрытия. Это не техническая гарантия 100% аукционов: участие, показ и место зависят от допуска, релевантности, аукциона и бюджета. Отдельно измерять охват каталога и долю доступных показов. Не обещать конкретные проценты до оценки спроса и стоимости.

## Проверяемая спецификация новой рекламы
- Таблица покрытия: query_family → точная модель/вариант → URL → offerId → GTIN/MPN → наличие/доставка → политика → статус Merchant по назначению/стране → допуск кампанией → показы/клики → причина пробела → исправление.
- Для каждого продаваемого допустимого SKU — явный статус: покрыт / нет спроса в наблюдаемом периоде / недостаточно данных / блокируется / осознанно исключён с причиной. Нельзя молча исключать модели по цене или порогу вклада.
- Shopping: правдивые title, brand, GTIN/MPN, вариант, цена/доставка; правильные feedLabel/страна, listing scope и product groups; проверка минус-слов, расписания, географии, ставок и бюджета.
- Shopping сопоставляет запросы с данными товара, а не со списком exact keywords. Добавление точных ключей в Search само по себе не даёт карточек Shopping.
- Search: отдельный проект модельных групп и релевантных объявлений с посадочной на точный товар. Exact match может включать близкие варианты; проверить реальные запросы и минусы. Не объединять разные комплектации под одним обещанием.
- Подготовить обоснованный выбор Standard Shopping/PMax и их роли. Не утверждать, что PMax автоматически обеспечит покрытие всех моделей. Прозрачность модельного охвата — критерий выбора.
- Новая структура сначала проектируется и проверяется; переход со старой — с картой перекрытий, этапами включения, приёмкой и откатом. Новая стратегия не означает новый рекламный аккаунт или немедленное удаление старых кампаний.

## Метрики и приёмка
1. Доля пригодных SKU с подтверждённым допуском Merchant и кампании — целевой полный охват согласованного ассортимента.
2. Для спросовых моделей: товарные показы и отдельные поисковые запросы, доля полученных/потерянных показов и причины, где Google предоставляет эти метрики.
3. Нельзя считать campaign impression share долей всех поисков модели в Словакии; знаменатель — оценка допустимых аукционов.
4. Нулевые показы разбирать по SKU; не приписывать их только бюджету. Проверить допуск, спрос, релевантность, отбор, географию/расписание.
5. Обе поверхности проверяются отдельно: Shopping-карточки и Search-текст. Суммарные показы аккаунта не закрывают эту задачу.
6. Бюджетные сценарии охвата и экономический предел согласуются отдельно. Нельзя молча подменить цель покрытия узкой выборкой самых доходных моделей.
7. Самопоиск владельца — полезный контрольный сигнал; основной контроль — отчёты и доступные диагностические инструменты. Отсутствие на одном скриншоте не равно нулю всего спроса.
8. До масштабирования — проверка покупки и возвратов по методике проекта. Проблемы отдельных оружейных SKU не останавливают проектирование рекламы допустимых биноклей/телескопов.
