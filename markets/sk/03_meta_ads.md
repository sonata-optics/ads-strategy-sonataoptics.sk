# Meta SK — ассортимент и первые гипотезы

### ChatGPT Review / 2026-11-14

**Статус:** стратегическая заготовка. В этой итерации выгружены Google и Merchant; кабинет Meta не проверялся, бюджеты и кампании Meta не изменялись.

**Согласовано:** прицелы — основной ассортимент владельца, который необходимо учитывать в стратегии. Нельзя строить стратегию всего бизнеса только по урезанному Google-фиду. Полный опубликованный ассортимент: ../../data/catalog/2026-11-14/README.md.

### Red Teaming / Критика

1. Нельзя обещать запуск платной рекламы прицелов в Meta без проверки актуального правила и конкретного товара. Старые упоминания «scopes/sights 18+» не являются достаточным подтверждением текущей допустимости. Правила Ads, Commerce и органики различаются; актуальная первичная страница по оружейным аксессуарам в этой сессии недоступна.
2. Автоматическая загрузка всего ассортимента в динамический каталог может смешать разрешённые товары с ограниченными. Нужен отдельный статус допуска для каждого назначения и формата.
3. Дорогую оптику нельзя оценивать только по покупке в один визит: консультации и демонстрации нужно связать с последующей продажей. При этом лид/клик по телефону не равен продаже.
4. Meta CPC/CPM/CR и ROAS пока неизвестны: прогнозы не выдумывать и не переносить из Google.

**Контр-предложение:**

| Блок | Гипотеза / путь клиента | Проверяемый результат |
|---|---|---|
| Прицелы — основной коммерческий блок | Составить SKU-матрицу: оптический, ночной, тепловизионный прицел, насадка; уточнить аудитории и возражения; проверить допустимость платного, органического и коммерческого форматов отдельно | Подтверждённый статус канала для каждой подкатегории; затем согласованный план. До проверки не запускать и не обещать охват |
| Наблюдательные тепловизоры | Сравнение реальных наблюдательных задач, демонстрация в шоуруме, консультация | Квалифицированная заявка → состоявшаяся демонстрация → подтверждённая продажа |
| Бинокли и зрительные трубы | Короткий показ различий для природы, птиц, туризма | Покупка и вклад после рекламных затрат |
| Smart-телескопы / первый телескоп | Показ опыта пользователя и требований к комплекту без обещаний невозможных изображений | Продажа или квалифицированная консультация |
| Junior Lab | Подарок, который взрослый использует с ребёнком; честное видео комплекта | Покупка, возвраты и маржа |
| Лабораторные микроскопы | Подбор под прикладную задачу и комплектацию | Квалифицированная B2B-заявка → предложение → оплата |

Нельзя обходить запреты переименованием прицела, скрытой посадочной, подменой товара или маскировкой объявления. Если категория не допускается в Meta Ads, она всё равно остаётся в ассортиментной стратегии; альтернативные каналы требуют отдельной проверки.

**Следующий шаг:** получить первичный актуальный текст Meta по прицелам; проверить подключённые Meta-кабинеты, каталог, отклонения и данные за 90 дней; после этого предложить конкретные креативы и бюджеты. Существующие одобренные объявления не являются сами по себе гарантией разрешения всей категории.
