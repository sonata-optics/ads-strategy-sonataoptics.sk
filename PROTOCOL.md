# AI Multi-Agent Collaboration Protocol
**Target Project:** Sonata Optics E-commerce (`.sk`, `.pl`, `.at`, `.cz`)

Каждый AI-участник (Claude, ChatGPT, Grok, Gemini), открывающий этот репозиторий, обязан следовать данному протоколу.

---

## 1. Роли и зоны ответственности

| Модель | Основной фокус | Ключевые артефакты |
| :--- | :--- | :--- |
| **Claude (Code / Cowork)** | Анализ данных рекламных кабинетов, юнит-экономика, когортный анализ, глубокий факт-чекинг. | `/data/`, скрипты выгрузок, математика ROAS |
| **ChatGPT** | Перфоманс-маркетинг в Meta Ads, креативные концепты, углы позиционирования (angles), CJM. | `/markets/*/03_meta_ads.md`, сценарии UGC/креативов |
| **Gemini** | Архитектура Google Ads (PMax, Search, Shopping), семантика, фиды, синергия каталога. | `/markets/*/02_google_ads.md`, GMC-фиды |
| **Grok** | Red Teaming (жесткая критика), выявление рисков слива бюджета, правовые ограничения ЕС. | Ревизия каждого файла, блок «Критика и риски» |

---

## 2. Формат участия и правок

1. **Никакой слепой похвалы:** Каждое ревью документа ОБЯЗАНО содержать раздел `### Red Teaming / Критика`, где указываются минимум 2 слабых места предложенной идеи.
2. **Факты важнее мнений:** Если предлагается канал или бюджет, должны быть указаны предполагаемые:
   * CPC / CPM для Словакии в нише Outdoor/Optics.
   * Ожидаемый CR (Conversion Rate) сайта.
   * Требуемый целевой ROAS с учётом маржинальности.
3. **Особый фокус на регуляторику ЕС:**
   * Внимание категории **Тепловизоры / Приборы ночного видения**: жесткие правила Google Ads / Meta Ads касательно товаров военного/двойного назначения и охоты (weapons/weapon accessories policy).

---

## 3. Шаблон отзыва (Review Template)

При комментировании или дополнении стратегии используйте следующую структуру:
```markdown
### [AI_NAME] Review / [DATE]
- **Согласовано:** (что принято безоговорочно)
- **Критика и узкие места:** (почему это может не сработать или слить бюджет)
- **Контр-предложение:** (конкретная корректировка с цифрами/действиями)
- **Следующий шаг:** (что передается на доработку следующему агенту)
```
